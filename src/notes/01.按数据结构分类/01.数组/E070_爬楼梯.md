# E070. 爬楼梯

[题目链接](https://leetcode.cn/problems/climbing-stairs/)

每次可以爬 1 或 2 个台阶，求到达 n 阶的不同方法数。1 <= n <= 45。

示例：n = 2 时答案为 2；n = 3 时答案为 3。顺序不同算不同方法，例如 1+2 和 2+1。

## 第一次理解动态规划

从最后一步入手：到达第 i 阶，最后一步只能来自第 i-1 阶或第 i-2 阶。这两类方案互不重复，且覆盖全部可能，所以方法数相加。

定义 f(i) 为到达第 i 阶的方法数，则 f(1)=1，f(2)=2，f(i)=f(i-1)+f(i-2)。从小到大计算并保存已经得到的答案，就能复用较小问题的结果。

## 用户的数组版本

用户采用了从 0 开始存储的定义：dp[i] 表示到达第 i+1 阶的方法数，因此 dp[0]=1，dp[1]=2，循环从 i=2 到 n-1，返回 dp[n-1]。这与 f(i) 的台阶编号定义只是错开一位。

用户创建 new int[n+1]，因此 n=1 时数组长度为 2，访问 dp[1] 合法。此前教练回复中“不能避免越界”的说法是口误。若改为 new int[n]，则需要在设置 dp[1] 前处理 n=1。

## 空间优化

每轮只依赖前两个状态，可以用 lastTwo 和 lastOne 保存。循环开始时，lastTwo=f(i-2)，lastOne=f(i-1)。先计算 answer，再移动状态：

```java
answer = lastOne + lastTwo;
lastTwo = lastOne;
lastOne = answer;
```

更新后 lastTwo=f(i-1)、lastOne=f(i)，恰好供下一轮使用。不能提前覆盖 lastTwo，否则会丢失计算所需的旧值。

## 最终题解

```java
public int climbStairs(int n) {
    int lastTwo = 1;
    if (n == 1) {
        return lastTwo;
    }
    int lastOne = 2;
    int answer = 2;
    for (int i = 3; i <= n; i++) {
        answer = lastOne + lastTwo;
        lastTwo = lastOne;
        lastOne = answer;
    }
    return answer;
}
```
