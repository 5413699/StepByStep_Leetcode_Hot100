# E70-爬楼梯

[力扣原题](<https://leetcode.cn/problems/climbing-stairs/>)

<details>
<summary>题干、示例与限制</summary>

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**示例 1**

输入：`n = 2`

输出：`2`

解释：有两种方法可以爬到楼顶。

1. 1 阶 + 1 阶
2. 2 阶

**示例 2**

输入：`n = 3`

输出：`3`

解释：有三种方法可以爬到楼顶。

1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶

**提示**

- `1 <= n <= 45`

## 复杂度与边界

数组版和滚动版都从较小台阶递推到目标台阶，**时间复杂度均为 O(n)**。数组版保存中间结果，额外空间 O(n)；滚动版只保存固定数量的整数，**额外空间 O(1)**。

- `n = 1`：数组版的数组长度为 2，初始化 dp[1] 合法，返回 dp[0] = 1；滚动版直接返回 lastTwo = 1。
- `n = 2`：数组版直接返回 dp[1] = 2；滚动版不进入循环，返回初始 answer = 2。
- `n = 45`：方法数为 1836311903，仍在 Java int 的范围内。
- 数组版的 `dp[i]` 表示第 i + 1 阶；滚动版用 f(i) 表示第 i 阶，可以避免两套下标混用。
- 更新状态时先执行 `answer = lastOne + lastTwo`，再执行 `lastTwo = lastOne`、`lastOne = answer`，计算新值前不能丢失旧值。
