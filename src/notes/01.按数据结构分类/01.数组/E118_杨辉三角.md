给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在杨辉三角中，每个数是它左上方和右上方的数的和。

**示例 1**

输入：`numRows = 5`

输出：`[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`

**示例 2**

输入：`numRows = 1`

输出：`[[1]]`

**提示**：`1 <= numRows <= 30`

## 最终题解

### 逐行动态规划（最终版本）（最终版本）

逐行保存杨辉三角。每行首尾填 1，中间位置由上一行相邻元素相加得到。

时间复杂度：O(numRows²)；额外空间：O(numRows²)（包含返回结果）。

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> ans = new ArrayList<>();

        // 开始加入答案
        for(int i = 0; i < numRows; i++){
            List<Integer> row =  new ArrayList<>();
            // 注意第i行有i+1个元素
            for(int j = 0; j <= i; j++){
                // 头尾的数字是1
                if(j == 0 || j == i){
                    row.add(1);
                } else {
                    row.add(ans.get(i - 1).get(j - 1) + ans.get(i - 1).get(j));
                }
            }
            ans.add(row);
        }

        return ans;
    }
}
```

## 复杂度与边界

共有约 `numRows² / 2` 个元素需要生成，因此时间复杂度为 **O(numRows²)**。返回结果本身需要保存这些元素，空间复杂度为 **O(numRows²)**；除去返回结果的辅助空间为 O(numRows)。

- 第 `i` 行有 `i + 1` 个元素，最后一个下标是 `i`。
- 第 0 行只有一个首尾重合的 `1`。
- `numRows = 1` 时循环只执行一次，不会访问 `ans.get(-1)`。
- 中间位置 `j` 满足 `1 <= j < i`，此时上一行的 `j - 1` 和 `j` 一定存在。
