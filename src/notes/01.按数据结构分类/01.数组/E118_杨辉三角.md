<summary>题干、示例与限制</summary>

给定一个非负整数 `numRows`，生成「杨辉三角」的前 `numRows` 行。

在**杨辉三角**中，每个数是它左上方和右上方的数的和。

**示例 1**

输入：`numRows = 5`

输出：`[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`

**示例 2**

输入：`numRows = 1`

输出：`[[1]]`

**提示**

- `1 <= numRows <= 30`

## 最终题解

### 逐行动态规划（最终版本）

按行创建独立的 row，首尾填 1，中间读取上一行相邻元素。只有这一种有效解法；教练的 previousRow 写法是相同算法的写法变化。

时间复杂度：O(numRows²)；额外空间：O(1)（不含返回结果）；结果空间 O(numRows²)。

**勘误／更新说明**

下面保留我最终版本的全部注释与变量名，仅补充独立 Java 编译所需的 `List`、`ArrayList` 导入。LeetCode 通常已提供这些导入，原算法没有编译或逻辑错误。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> ans = new ArrayList<>();

        // 开始加入答案
        for(int i = 0; i < numRows; i++){
            List<Integer> row =  new ArrayList<>();
            // 注意第i行有i+1个元素
            for(int j = 0; j <= i; j++){
                // 头尾的数字是1
                if(j == 0 || j == i){
                    row.add(1);
                }
                else {
                    row.add(ans.get(i - 1).get(j - 1) + ans.get(i - 1).get(j));
                }
            }
            ans.add(row);
        }

        return ans;
    }
}
```

## 复杂度与边界

设 R = numRows。共生成 `1 + 2 + … + R = R(R + 1) / 2` 个元素；底层使用 ArrayList，get 为 O(1)，末尾 add 为摊还 O(1)，所以**时间复杂度 O(R²)**。

**返回结果占 O(R²)，不含结果的辅助空间为 O(1)**。每个 row 最终都直接放进 ans，属于输出本身；循环只额外维护 i、j 和引用变量。若把尚未放进 ans 的当前行单独计作临时空间，可说最多 O(R)，但这行不是额外复制，不应在扣除整个输出后重复计算。上一版笔记的辅助空间表述已据此澄清。

- `R = 1`：i = j = 0，首尾重合只添加一个 1，返回 `[[1]]`；不会走到 `ans.get(-1)`。
- 第 i 行 j 遍历闭区间 `[0, i]`。只有中间 `1 <= j < i` 才访问上一行 `[0, i-1]` 中的 j-1 和 j。
- 每行都新建 `row`，避免多个行位置共享一个可变列表。
- `R = 30`：最大元素为 C(29,14) = 77558760，在 Java int 范围内。
