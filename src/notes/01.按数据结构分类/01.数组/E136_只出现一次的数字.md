# E136. 只出现一次的数字

[LeetCode 题目链接](https://leetcode.cn/problems/single-number/)

给定一个非空整数数组 `nums`，除一个元素只出现一次外，其余元素均出现两次。在线性时间和常量额外空间内找出只出现一次的元素。

## 示例

```text
输入：nums = [2,2,1]
输出：1
```

```text
输入：nums = [4,1,2,1,2]
输出：4
```

```text
输入：nums = [1]
输出：1
```

## 提示

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除一个元素只出现一次外，其余元素均出现两次

## 面试版思路

把数组中的所有数字依次异或。异或满足以下性质：

```text
a ^ a = 0
a ^ 0 = a
异或满足交换律和结合律
```

因此，无论两个相同数字是否相邻，都可以看作先将它们配对抵消为 `0`。所有出现两次的数字都会被消去，最终只剩下出现一次的数字。

例如：

```text
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4
```

## 为什么初始化为 0

`0` 是异或运算的单位元，即 `0 ^ a = a`。所以将累计结果 `ans` 初始化为 `0`，不会改变第一个数字，同时也能正确处理只有一个元素的数组。

## 负数为什么同样适用

Java 对整数的二进制位执行异或。同一个负数的每一位都完全相同，因此它与自身异或后每一位都变成 `0`，仍满足 `a ^ a = 0`。算法不依赖数字的正负。

## 代码要点

- `ans` 初始化为 `0`。
- 遍历数组并执行 `ans = ans ^ nums[i]`，也可以简写为 `ans ^= nums[i]`。
- 不需要排序、哈希表或额外数组。
- 该方法依赖题目的关键条件：除一个元素外，其余元素都恰好出现两次。

## 易错点

- `^` 在 Java 中表示异或，不是乘方。
- 使用哈希表虽然能达到 `O(n)` 时间，但需要 `O(n)` 额外空间，不满足题目要求。
- 排序后查找相邻元素需要 `O(n log n)` 时间，也不满足线性时间要求。
- 如果其他元素出现三次，简单异或不能将它们抵消，本方法不能直接套用。

## 复杂度

- 时间复杂度：`O(n)`，每个元素参与一次异或。
- 空间复杂度：`O(1)`，只使用一个累计变量。

## 面试表达

题目要求线性时间和常量空间，而且除一个数外，其余数字都出现两次。我利用异或中相同数字异或为零、零与数字异或仍是该数字，以及交换律和结合律，把全部元素累计异或。成对元素都会抵消，最后保留下来的就是只出现一次的数字。
