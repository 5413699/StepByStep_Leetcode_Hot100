51. N 皇后

按照国际象棋的规则，皇后可以攻击与之处在同一行、同一列或同一斜线上的棋子。

`n` 皇后问题研究的是如何将 `n` 个皇后放置在 `n x n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n`，返回所有不同的 `n` 皇后问题的解决方案。

每一种解法包含一个不同的 `n` 皇后问题的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表皇后和空位。

示例 1：

```text
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：4 皇后问题存在两个不同的解法。
```

示例 2：

```text
输入：n = 1
输出：[["Q"]]
```

提示：

- `1 <= n <= 9`

## 面试版思路

由于皇后可以攻击同一行、同一列和两条斜线，所以合法方案中每一行最多只能放一个皇后。又因为一共要放 `n` 个皇后，棋盘也有 `n` 行，因此可以把问题转化为：每一行固定放一个皇后，递归决定这一行放在哪一列。

回溯时，用 `row` 表示当前正在处理第几行。对于当前行，枚举每一个 `col`，判断该列、左上到右下斜线、右上到左下斜线是否已经被占用。如果被占用，说明当前位置会被攻击，直接跳过；否则就在当前位置放置皇后，并标记对应列和斜线，然后递归处理下一行。

当递归返回时，需要撤销当前皇后和对应状态标记，继续尝试当前行的其他列。若 `row == n`，说明每一行都成功放置了一个皇后，此时将当前棋盘转换成 `List<String>`，加入答案。

## 代码要点

- `char[][] board` 表示当前棋盘，初始化后需要把每个格子填成 `'.'`，不能只依赖 `new char[n][n]` 的默认值。
- `Arrays.fill(board[i], '.')` 等价于把第 `i` 行所有元素都赋值为 `'.'`，可以省掉内层循环。
- `cols[col]` 记录某一列是否已经有皇后。
- 左上到右下斜线可以用 `row - col` 区分；为了避免负数下标，代码中使用 `row - col + n`。
- 右上到左下斜线可以用 `row + col` 区分。
- 判断、标记、撤销必须使用同一套斜线下标，最好先计算 `d1`、`d2`，避免写反。
- `new String(board[i])` 可以把第 `i` 行 `char[]` 直接转换成题目要求的字符串。

## 本题新用法

- `Arrays.fill(board[i], '.')`：`board[i]` 是二维数组的第 `i` 行，也就是一个 `char[]`，所以这个调用会把这一整行都填成 `'.'`。
- `new String(board[i])`：`board[i]` 是一行 `char[]`，可以直接构造成字符串，正好用于生成 N 皇后答案中的一行。

## 思考过程

一开始先确认了皇后的攻击规则：同一列不能放；左上到右下斜线上 `row - col` 相同；右上到左下斜线上 `row + col` 相同。随后把题目从“在棋盘任意格子放皇后”转成“逐行决定这一行放在哪一列”。

实现中主要卡在几个 Java 和回溯细节：`char[][]` 新建后默认值不是 `'.'`，需要用 `Arrays.fill` 按行初始化；二维数组的一行 `board[i]` 本身是 `char[]`，可以直接通过 `new String(board[i])` 转成字符串；斜线数组不是 `n` 条，而是接近 `2n - 1` 条；判断、放置和撤销时，斜线下标公式必须完全一致。

关键突破是理解“每一层递归固定处理一行”，这样同行冲突天然不存在，只需要检查列和两类斜线。之后代码就变成标准的选择、递归、撤销。

## 题解

```java
public List<List<String>> solveNQueens(int n) {
    List<List<String>> ans = new ArrayList<>();
    char[][] board = new char[n][n];
    boolean[] cols = new boolean[n];
    boolean[] leftUpRightDown = new boolean[2 * n];
    boolean[] rightUpLeftDown = new boolean[2 * n];

    for (int i = 0; i < n; i++) {
        Arrays.fill(board[i], '.');
    }

    backtrack(ans, board, cols, leftUpRightDown, rightUpLeftDown, 0, n);
    return ans;
}

private void backtrack(List<List<String>> ans, char[][] board, boolean[] cols,
                       boolean[] leftUpRightDown, boolean[] rightUpLeftDown,
                       int row, int n) {
    if (row == n) {
        List<String> curAns = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            curAns.add(new String(board[i]));
        }
        ans.add(curAns);
        return;
    }

    for (int col = 0; col < n; col++) {
        int d1 = row - col + n;
        int d2 = row + col;
        if (cols[col] || leftUpRightDown[d1] || rightUpLeftDown[d2]) {
            continue;
        }

        board[row][col] = 'Q';
        cols[col] = true;
        leftUpRightDown[d1] = true;
        rightUpLeftDown[d2] = true;

        backtrack(ans, board, cols, leftUpRightDown, rightUpLeftDown, row + 1, n);

        board[row][col] = '.';
        cols[col] = false;
        leftUpRightDown[d1] = false;
        rightUpLeftDown[d2] = false;
    }
}
```

## 复杂度

时间复杂度：`O(n!)`。粗略理解是第一行最多有 `n` 种选择，第二行最多 `n - 1` 种列选择，后续继续减少；斜线剪枝会减少实际搜索量，但搜索规模通常用 `O(n!)` 描述。

空间复杂度：`O(n^2)`。主要来自棋盘 `board`，递归深度和三个布尔数组是 `O(n)`。如果计算答案存储，还需要额外保存所有合法方案。

## 易错点

- 只写 `new char[n][n]` 不会得到 `'.'`，默认值是不可见的 `'\u0000'`。
- `Arrays.fill(board[i], '.')` 是填充第 `i` 行，不是只填一个元素。
- 斜线数量不是 `n`，而是 `2n - 1`，使用数组时要处理 `row - col` 的负数偏移。
- 判断、标记、撤销时不能一处写 `row - col`，另一处写 `col - row`。
- 找到完整方案后要 `return`，否则继续访问 `board[row][col]` 会越界。
- 保存答案时要保存当前棋盘的字符串结果，不要保存会被后续回溯修改的临时对象引用。

## 掌握状态

- 状态：提示后完成，需要二刷。
- 当前主要突破：能把 N 皇后建模为逐行决策，并用列和两条斜线状态做剪枝。
- 当前主要卡点：二维 `char[][]` 初始化、`new String(char[])`、斜线数组长度与下标偏移、判断和标记公式保持一致。
- 下一次复习重点：独立写出 `d1 = row - col + n`、`d2 = row + col`，并完整口述为什么每层递归只处理一行。
