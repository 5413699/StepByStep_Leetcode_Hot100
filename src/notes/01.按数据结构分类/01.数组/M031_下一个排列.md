# M031. 下一个排列

[LeetCode 题目](https://leetcode.cn/problems/next-permutation/)

给定整数数组 nums，原地修改成字典序中紧邻的下一个更大排列。若不存在更大排列，则重排为最小排列。只允许常数额外空间。

```text
[1,2,3] -> [1,3,2]
[3,2,1] -> [1,2,3]
[1,1,5] -> [1,5,1]
```

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 100`

## 核心思路

字典序由从左往右第一个不同的位置决定。要得到刚好更大的排列，就要尽量保留左侧前缀，让尽可能靠右的位置增大尽可能少，再让后缀尽可能小。

1. 从右往左找第一个满足 `nums[i] < nums[i + 1]` 的位置。它右边的后缀非递增，单独重排后缀不可能变得更大。
2. 从最右边找第一个严格大于 `nums[i]` 的数，与它交换。后缀非递增，因此找到的是最小可用数。
3. 交换后的后缀仍非递增，反转成升序就是最小后缀。
4. 若找不到升序位置，整个数组已是最大排列，反转整个数组回到最小排列。

```text
[5,4,2,3,1]
     ↑ ↑
找到 2 < 3，右边 [3,1] 非递增
从右跳过 1，选择 3 与 2 交换
[5,4,3,2,1]
反转后缀 [2,1]
[5,4,3,1,2]
```

## 为什么交换后还能直接反转

设原枢轴值为 x。选择的是后缀中最右侧的大于 x 的数，它右侧所有数都小于等于 x，左侧所有数都不小于被换走的数。因此将 x 放入该位置，后缀仍然非递增。反转即可得到升序，无须排序。

## 本次训练摘要

- 第一反应：在引导示例 `[1,2,5,4,3]` 中，正确选择 3 替换 2，并让后半段升序。
- 表达修正：全非递增意味着没有“变大”的空间，而不是没有“缩小”的空间。
- 初稿已经正确写出外层倒序扫描、反转方法和全降序兜底，但直接与最后一位交换。
- 反例 `[2,3,1]`：最后一位 1 不能替换 2，必须从右向左跳过它，找到 3。
- 最终补上 `while (nums[j] <= nums[i]) j--;`，理解了必须跳过重复值，否则交换后字典序不变。
- 用户最后询问反转数组的现成方法与简化写法；正式解答保留其原来的 for 双指针实现。

## 易错点与边界

- 寻找枢轴必须是严格小于；寻找替换值必须严格大于。
- `j` 不会越界，因为至少 `nums[i + 1]` 严格大于枢轴。
- 反转从 `i + 1` 开始，不包含已选定的新枢轴。
- 找到并处理后立即 return，避免最后又反转整个数组。
- 单元素、全相等、全降序数组，都可以直接走全数组反转分支。
- `[1,5,1]` 用于检查 <=；`[2,3,1]` 用于检查不能直接交换末尾。

## 反转 int[] 的写法

用户的 for 写法已是简洁的标准双指针模板。也可以直接移动参数，省去额外声明 i、j：

```java
public void reverse(int start, int end, int[] nums) {
    while (start < end) {
        swap(start, end, nums);
        start++;
        end--;
    }
}
```

start、end 是按值传入的整数，移动它们不会改变调用者的下标变量；nums 引用指向同一个数组，所以交换会修改原数组。两种写法效率相同。

Java 标准库 Arrays 没有 reverse(int[])。Collections.reverse(List<?>) 用于可修改的 List，不能直接反转 int[]。不要用 Collections.reverse(Arrays.asList(nums))：当 nums 是 int[] 时得到的是只有一个数组元素的 List<int[]>，不会反转内部整数。

来源：[Java 21 Arrays](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Arrays.html)、[Java 21 Collections.reverse](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Collections.html#reverse(java.util.List))。

## 复杂度与面试表达

最多做一次枢轴扫描、一次替换值扫描、一次后缀反转，因此时间 O(n)，额外空间 O(1)。虽然语法上出现嵌套循环，内层只会在找到枢轴后执行一次，随后立即返回，并非 O(n²)。

面试表达：我从右往左寻找可以增大的最右位置，再从非递增后缀的右侧找最小的严格更大元素交换，最后反转后缀，使增加后的排列尽可能小。如果不存在这样的位置，就将整个数组反转为最小排列。
