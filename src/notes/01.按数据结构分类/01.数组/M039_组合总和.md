39. 组合总和

给你一个无重复元素的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为 `target` 的所有不同组合，并以列表形式返回。可以按任意顺序返回这些组合。

`candidates` 中的同一个数字可以无限制重复被选取。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。

示例 1：

```text
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：2 和 3 可以形成一组候选，2 + 2 + 3 = 7。7 也是一个候选，7 = 7。
```

示例 2：

```text
输入：candidates = [2,3,5], target = 8
输出：[[2,2,2,2],[2,3,3],[3,5]]
```

示例 3：

```text
输入：candidates = [2], target = 1
输出：[]
```

提示：

- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- `candidates` 的所有元素互不相同
- `1 <= target <= 40`

## 面试版思路

首先对原始整数数组排序，保证候选数从小到大排列，方便后续剪枝。随后使用回溯逐个尝试候选数，用 `remain` 记录当前组合距离目标值还差多少，用 `startIndex` 限制当前层从哪里开始选择，避免生成顺序不同但内容相同的重复组合。

每次选择一个数加入当前组合后，因为同一个数字可以被重复选取，所以下一层递归仍然从当前下标开始。若 `remain == 0`，说明当前组合刚好满足目标，将其加入答案；递归返回后撤销当前选择，继续尝试下一个候选数。

排序后，如果当前候选数已经大于 `remain`，那么后面的候选数也一定更大，不可能组成合法答案，因此直接结束当前层循环，完成剪枝。

## 代码要点

- `path` 表示当前正在构造的组合。
- `remain` 表示当前组合距离目标值还差多少。
- `startIndex` 表示当前层从哪个下标开始枚举候选数，用来避免 `[2,2,3]` 和 `[2,3,2]` 这种重复组合。
- 因为当前数字可以重复使用，递归时传 `i`，不是 `i + 1`。
- 找到答案时要保存 `path` 的拷贝：`ans.add(new ArrayList<>(path))`。
- 排序后如果 `candidates[i] > remain`，当前层后面的数也都更大，可以 `break` 剪枝。

## 练习关注点

- 子集题中每个数只能使用一次，所以递归传 `i + 1`。
- 本题中每个数可以重复使用，所以递归传 `i`。
- `startIndex` 的作用不是凑和，而是限制选择顺序，避免重复组合。
- `break` 表示结束当前层循环，不是跳过当前数看下一个数；能用 `break` 的前提是数组已经排序。

## 易错点

- 加入答案时不能直接 `ans.add(path)`，否则后续回溯修改 `path` 会影响答案中的内容。
- 不要用 `used` 数组。本题是组合问题，通过 `startIndex` 控制不回头选择即可。
- 递归传 `i + 1` 会导致同一个数字不能重复使用，漏掉 `[2,2,3]` 这类答案。
- 如果没有排序，不能在 `candidates[i] > remain` 时直接 `break`，因为后面可能还有更小的数。
- `break` 不是 `continue`：`break` 会结束当前层循环。

## 复杂度

设 `n = candidates.length`，目标值为 `target`，候选数最小值为 `min`：

- 时间复杂度：搜索树规模与可行组合数量和分支剪枝有关，粗略上界可看作 `O(n^(target / min))`。
- 空间复杂度：不算答案为 `O(target / min)`，主要是递归深度和 `path`；如果计算答案存储，还需要保存所有合法组合。
