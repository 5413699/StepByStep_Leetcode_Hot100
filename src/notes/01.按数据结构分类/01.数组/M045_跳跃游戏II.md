# M045-跳跃游戏 II

[LeetCode 题目链接](https://leetcode.cn/problems/jump-game-ii/)

给定一个长度为 `n` 的 0 索引整数数组 `nums`，初始位置在下标 `0`。`nums[i]` 表示从下标 `i` 向后跳转的最大长度。返回到达下标 `n - 1` 的最小跳跃次数，题目保证终点可达。

## 示例

```text
输入：nums = [2,3,1,1,4]
输出：2
解释：先从下标 0 跳到下标 1，再从下标 1 跳到终点。
```

```text
输入：nums = [2,3,0,1,4]
输出：2
```

## 提示

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 1000`
- 题目保证可以到达 `n - 1`

## 思路

把一次跳跃能够覆盖的下标范围看作一层。扫描当前层的所有位置时，不立即决定具体跳到哪一个位置，而是维护从这一层出发，下一层最远能够到达的下标 `farthest`。

`curEnd` 表示当前层的右边界。当扫描到 `i == curEnd` 时，说明当前层的所有候选位置都已经检查完成，此时才真正增加一次跳跃，并把下一层的右边界更新为 `farthest`。

本题代码保留了提前返回：扫描当前层时，如果 `farthest` 已经覆盖终点，说明再跳一次即可到达，因此返回 `step + 1`。

## 贪心正确性

在跳跃次数相同的前提下，当前层中每个可达位置都是下一跳的候选点。选择其中能够让下一层覆盖范围最远的结果，不会丢失任何更近的位置，因为从更远的覆盖边界形成的可达范围包含本层扫描得到的所有较近结果。因此，每扫描完一层才增加一次 `step`，得到的就是到达终点的最少跳跃次数。

## 变量含义

- `step`：已经完成的跳跃次数。
- `curEnd`：当前这次跳跃所能覆盖的右边界。
- `farthest`：扫描当前层时发现的、下一跳能够到达的最远位置。

## 易错点

- 扫描一个候选下标不等于执行了一次跳跃，不能在每次循环中都执行 `step++`。
- 只有扫描到当前层边界 `i == curEnd` 时，才进入下一层并增加跳跃次数。
- 如果使用提前返回，`farthest` 覆盖终点时应返回 `step + 1`，因为这一步尚未计入。
- 如果不使用提前返回，循环只需扫描到倒数第二个下标，即 `i < nums.length - 1`，避免站在终点后多计算一次跳跃。
- `nums.length == 1` 时已经位于终点，循环不会执行，返回 `0`。

## 复杂度

- 时间复杂度：`O(n)`，每个下标最多扫描一次。
- 空间复杂度：`O(1)`，只维护常数个变量。

## 面试表达

我把相同步数能够到达的位置看作 BFS 的一层，但不使用队列，而是用 `curEnd` 记录当前层边界。扫描这一层时，用 `farthest` 维护下一层的最远边界；扫描到 `curEnd` 才说明这一层结束，此时跳跃次数加一。这样每次扩展一层对应一次跳跃，因此第一次覆盖终点时的层数就是最少跳跃次数。

## 本次训练记录

- 第一反应：能够枚举当前可达位置，并比较每个位置下一步最远能跳到哪里。
- 卡壳点：最初把“扫描一个可达位置”误认为“完成一次跳跃”，导致 `step` 在循环的每个位置都增加。
- 关键突破：区分当前层边界 `curEnd` 和下一层最远边界 `farthest`，只在一层扫描结束时增加 `step`。
- 边界理解：题目保证终点可达，因此不需要不可达分支；循环排除终点可以自然避免多记一次跳跃。
