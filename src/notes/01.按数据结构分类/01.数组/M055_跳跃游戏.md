# M055. 跳跃游戏

给你一个非负整数数组 `nums`，你最初位于数组的第一个下标。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 `true`；否则，返回 `false`。

示例 1：

```text
输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1，再从下标 1 跳 3 步到达最后一个下标。
```

示例 2：

```text
输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样都会到达下标 3，而下标 3 的最大跳跃长度是 0，无法继续到达最后一个下标。
```

提示：

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^5`

## 面试版思路

从左到右遍历数组，维护当前已经能够到达的最远下标 `maxReach`。如果遍历到下标 `i` 时 `i > maxReach`，说明当前位置不可达，直接返回 `false`。否则用当前位置继续扩展最远范围：`maxReach = max(maxReach, i + nums[i])`。一旦 `maxReach >= nums.length - 1`，说明已经能够到达最后一个下标，返回 `true`。

## 为什么使用贪心

后续位置只关心当前能覆盖到的最远边界，而不关心到达这个边界的具体跳法。每次保留最大的可达下标，就不会丢失任何后续可能性。

## 代码要点

- `maxReach` 初始化为 `0`，因为数组第一个下标 `0` 是起点。
- 先判断 `i > maxReach`，再读取 `nums[i]`；只有当前位置可达时，才能用它扩展范围。
- 循环边界使用 `i < nums.length`，最后一个合法下标是 `nums.length - 1`。
- `nums[i]` 表示最多跳跃长度，不要求恰好跳到某个位置。

## 易错点

- 不要把快速排序的复杂度写成 `O(log n)`；本题并不需要排序。
- 不要写成 `i <= nums.length`，否则可能访问 `nums[nums.length]`。
- 不能只看当前位置的跳跃长度，要维护所有已达位置带来的最远范围。

## 复杂度

- 时间复杂度：`O(n)`，数组只遍历一次。
- 空间复杂度：`O(1)`，只使用一个最远位置变量。
