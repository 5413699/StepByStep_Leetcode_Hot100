# M198-打家劫舍

[力扣原题](<https://leetcode.cn/problems/house-robber/>)

<details>
<summary>题干、示例与限制</summary>

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你**不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

**示例 1**

输入：`[1,2,3,1]`

输出：`4`

解释：偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。偷窃到的最高金额 = 1 + 3 = 4。

**示例 2**

输入：`[2,7,9,3,1]`

输出：`12`

解释：偷窃 1 号房屋（金额 = 2）、3 号房屋（金额 = 9），接着偷窃 5 号房屋（金额 = 1）。偷窃到的最高金额 = 2 + 9 + 1 = 12。

**提示**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

### 滚动变量（最终版本）

只保留最近两个前缀的最优金额，适合仅需要最终答案的场景。

时间复杂度：O(n)；额外空间：O(1)。

**勘误／更新说明**

保留我的最终代码、变量和“初始化”注释，只整理空白与缩进。`length` 暂未使用，但不影响正确性，未擅自删除。相较滚动初稿的唯一逻辑修正是最终返回 lastOne。

```java
class Solution {
    public int rob(int[] nums) {
        int length = nums.length;
        int ans = nums[0];
        // 初始化
        int lastTwo = nums[0];
        if (nums.length == 1) {
            return lastTwo;
        }
        int lastOne = Math.max(lastTwo, nums[1]);

        for (int i = 2; i < nums.length; i++) {
            ans = Math.max(lastOne, lastTwo + nums[i]);
            lastTwo = lastOne;
            lastOne = ans;
        }
        return lastOne;
    }
}
```

## 复杂度与边界

设 n = nums.length。数组 DP 和滚动变量都只扫描一次，时间均为 **O(n)**；数组版额外空间 **O(n)**，滚动版额外空间 **O(1)**。

- `n = 1`：在访问 nums[1] 前返回 nums[0]。
- `n = 2`：循环不执行，返回 `lastOne = Math.max(nums[0], nums[1])`。本次真实反例为 `[1,2]`。
- **状态含义**：dp[i] 是前 i+1 间房的最优金额，不保证一定偷第 i 间。
- **更新顺序**：先用旧 lastOne、lastTwo 算 ans，再执行 lastTwo = lastOne，最后 lastOne = ans。若先覆盖旧状态，递推就可能使用错误信息。
- 补充边界：全为 0 时返回 0；房屋不一定按固定奇偶位置选择，例如 `[2,1,1,2]` 最优为 4。此例是收尾补充，不是本次发生的错误。
- n 最多 100，每间最多 400，最多选 50 间，答案不超过 20000，Java int 足够。
- 算法只读取 nums，不修改输入数组。
