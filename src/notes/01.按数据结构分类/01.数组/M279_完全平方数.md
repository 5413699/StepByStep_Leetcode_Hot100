# M279-完全平方数

[力扣原题](<https://leetcode.cn/problems/perfect-squares/>)

<details>
<summary>题干、示例与限制</summary>

给你一个整数 `n`，返回和为 **`n` 的完全平方数的最少数量**。

**完全平方数**是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

**示例 1**

输入：`n = 12`

输出：`3`

解释：`12 = 4 + 4 + 4`。

**示例 2**

输入：`n = 13`

输出：`2`

解释：`13 = 4 + 9`。

**提示**

- `1 <= n <= 10^4`。

## 最终题解

### 一维动态规划（最终版本）

按和从小到大计算各状态，枚举最后一个平方数并取最小值。需要保留更早的多个状态，不能直接套用爬楼梯只保留两个状态的写法。

时间复杂度：O(n√n)；额外空间：O(n)。

**勘误／更新说明**

沿用我的变量名和算法结构，保留全部原注释；仅规范格式，并在 dp[0] 原注释和“怎么写注释？”之后增加说明。算法无需修改。

```java
class Solution {
    public int numSquares(int n) {
        // 记录每个数需要几个完全平方数
        int[] dp = new int[n + 1];
        // 和为0只需要1个平方数
        // 勘误：和为0不需要任何完全平方数，下面的 dp[0] = 0 是正确的。
        dp[0] = 0;

        // 逐个后推需要完全平方数的数量
        for (int i = 1; i <= n; i++) {
            // 初始给dp[i]一个较大值，一个数需要完全平方数的数量不可能比这个数还多
            dp[i] = i + 1;
            // 怎么写注释？
            // 补充：枚举最后一个完全平方数 j*j，剩余和为 i-j*j，取总数量的最小值。
            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
}
```

## 复杂度与边界

- **时间 O(n√n)**：每个和 `i` 枚举 `1..⌊√i⌋`，总次数为这些枚举次数之和。
- **额外空间 O(n)**：长度为 `n+1` 的数组保存 `dp[0..n]`。
- **初始状态**：`dp[0]=0`。这里计数的是“用几个数”，不是“有几种方案”，不要套用爬楼梯的计数初始化。
- **初始上界**：组成 `i` 至多用 `i` 个 1，因此 `i+1`、`n+1` 均可；也可直接用合法方案数量 `i` 初始化。当前代码保留 `i+1`。
- **平方数边界**：从 `j=1` 开始，条件 `j*j<=i`；每个依赖下标位于 `[0,i-1]`，已计算完毕。
- **最大整数**：本实现使用 `Integer.MAX_VALUE` 初始化也可行，因为依赖总为有限值。一般存在不可达状态的 DP 不能盲目给哨兵加 1。
- **典型边界**：`n=1→1`，`n=12→3`，`n=13→2`，`n=25→1`，`n=10000→1`。在本题范围内 `j*j` 和数量均不会溢出 int。

## 面试表达与复习

**面试表达（整理稿）**：令 `dp[i]` 表示组成和 `i` 所需的最少完全平方数数量。枚举最后一个平方数 `j*j`，剩余和的最优解是 `dp[i-j*j]`，加上本次数量 1，再对所有选择取最小值。设置 `dp[0]=0`，从小到大计算。由于依赖状态更小，转移时已知；枚举覆盖最后一个平方数的所有可能，因此不会漏掉最优解。时间 `O(n√n)`，空间 `O(n)`。
