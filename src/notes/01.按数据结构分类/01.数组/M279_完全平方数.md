# M279-完全平方数

[力扣原题](https://leetcode.cn/problems/perfect-squares/)

<details><summary>题干、示例与限制</summary>

给定 `n`，返回和为 `n` 的完全平方数的最少数量。`1 <= n <= 10^4`。

示例：`12 = 4 + 4 + 4`，答案为 `3`；`13 = 4 + 9`，答案为 `2`。
</details>

## 最终答案：一维 DP

时间复杂度 `O(n√n)`，空间复杂度 `O(n)`。

```java
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            dp[i] = i + 1;
            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
}
```

## 本次训练记录

我理解了“固定最后一个完全平方数”的状态转移，并完成了可运行实现。教练补充：`dp[0] = 0` 表示组成 0 不需要数字；初始值设为 `i + 1` 可避免默认 0 干扰最小值。

## 复杂度与边界

`j*j <= i` 保证只枚举不超过当前和的平方数；`n=1` 时返回 `1`。使用 `Integer.MAX_VALUE` 可能在加 1 时溢出，因此采用 `i+1`。
