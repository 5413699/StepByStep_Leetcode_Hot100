给你一个整数数组 `coins`，表示不同面额的硬币；以及一个整数 `amount`，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数**。如果没有任何一种硬币组合能组成总金额，返回 `-1`。

你可以认为每种硬币的数量是无限的。

**示例 1**

输入：`coins = [1, 2, 5], amount = 11`

输出：`3`

解释：`11 = 5 + 5 + 1`。

**示例 2**

输入：`coins = [2], amount = 3`

输出：`-1`。

**示例 3**

输入：`coins = [1], amount = 0`

输出：`0`。

**提示**

- `1 <= coins.length <= 12`。
- `1 <= coins[i] <= 2^31 - 1`。
- `0 <= amount <= 10^4`。

## 最终题解

### 金额递增的一维动态规划（最终版本）

适用于每种面额可无限使用、求精确凑出目标金额所需最少硬币数的问题。固定最后一枚硬币，复用剩余金额的最优解；不需要排序，也不需要显式枚举每种硬币的使用次数。

时间复杂度：O(amount × coins.length)，amount=0 时 O(1)；额外空间：O(amount)，精确为 O(amount+1)。

保留我的 dp、i、j、coins、amount、循环结构和全部 8 条原注释。仅调整格式、补充 Arrays 导入，并在含义不完整的原注释后增加限定说明；没有改变最终算法。

```java
import java.util.Arrays;

class Solution {
    public int coinChange(int[] coins, int amount) {
        // 记录每个金额需要的硬币数
        int[] dp = new int[amount + 1];
        // 先将所有金额标记为暂时无法凑出
        Arrays.fill(dp, amount + 1);

        // 0元不需要硬币
        dp[0] = 0;
        // 计算最少需要的硬币个数
        for (int i = 1; i <= amount; i++) {
            // 枚举每一枚硬币
            for (int j = 0; j < coins.length; j++) {
                // 假如当前硬币超过了需要金额，说明凑不出了
                // 补充：只是当前这枚硬币不能用，其他面额仍需继续尝试。
                if (coins[j] > i) {
                    continue;
                }
                // 假如加入当前硬币
                dp[i] = Math.min(dp[i - coins[j]] + 1, dp[i]);
            }
        }
        // 假如最后都还没凑出来
        if (dp[amount] == amount + 1) {
            return -1;
        }

        return dp[amount];
    }
}
```

## 复杂度与边界

令 `A = amount`，`m = coins.length`。

- **时间 O(A × m)**：对每个正金额枚举全部面额；初始化另需 O(A+1)。包含 `A=0` 时可统一写作 O((A+1) × m)，实际零金额直接跳过循环，仅需常数时间。
- **额外空间 O(A)**：`dp` 有 `A+1` 个元素；严格包含零金额时写作 O(A+1)。输入数组不会被修改。
- **重复使用**：`dp[i-coins[j]]` 的最优方案可已含面额 `coins[j]`，再加一枚即可继续使用。金额递增且面额为正，所有依赖下标都小于 `i`。
- **不可达标记**：每枚硬币至少为 1，若某个金额能凑出，任一方案的硬币数不超过该金额。`amount+1` 大于所有合法答案；不可达旧状态加 1 后更大，不会误更新当前最小值。
- **整数范围**：`amount<=10000`，哨兵加 1 至多为 10002，不溢出。面额可能为 `Integer.MAX_VALUE`，先比较 `coins[j]>i` 再跳过，可避免负下标；不要先算 `i+coins[j]`。若改用最大整数作哨兵，必须防止不可达状态直接加 1。
- **零金额**：`dp[0]=0`，外层不执行，直接返回 0。
- **边界用例**：`[2],6→3`（重复使用），`[5,1],3→3`（无序），`[2],3→-1`（无解），`[1],0→0`（零金额），`[1],10000→10000`（最大数量）。

## 面试表达与复习

**面试表达（整理稿）**：定义 `dp[i]` 为凑出金额 `i` 的最少硬币数。固定最后一枚面额为 `coin` 的硬币，若 `coin<=i`，候选数量是 `dp[i-coin]+1`，对所有面额取最小值。初始化 `dp[0]=0`，其余为安全上界 `amount+1`。金额从小到大计算，较小金额的最优解已经求出，也可以已经使用相同面额，因此支持无限次使用。最后目标状态仍为哨兵则返回 -1，否则返回其值。时间 O(amount × coins.length)，额外空间 O(amount)。
