437. 路径总和 III

给定一个二叉树的根节点 root ，和一个整数 targetSum ，求该二叉树里节点值之和等于 targetSum 的 路径 的数目。

路径 不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

示例 1：

输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出：3
解释：和等于 8 的路径有 3 条，如图所示。

示例 2：

输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：3

提示:

二叉树的节点个数的范围是 [0,1000]
-10^9 <= Node.val <= 10^9
-1000 <= targetSum <= 1000

## 思路

### 暴力解法

二叉树中节点值之和等于 targetSum 的路径数目 =
以当前根节点作为起点的路径数量 +
左子树中节点值之和等于 targetSum 的路径数目（递归） +
右子树中节点值之和等于 targetSum 的路径数目（递归）。

可以递归地对每个节点都尝试作为路径起点。

以某个节点作为起点，和为 targetSum 的路径数目 =
只包含当前节点这一条路径是否满足和为 target（1/0） +
经过左孩子，和为 target - node.val 的路径数目（递归） +
经过右孩子，和为 target - node.val 的路径数目（递归）。

枚举每个节点作为路径起点。对于每个起点，再递归向下统计有多少条路径和等于目标值。
整体答案等于从当前节点出发的路径数量，加上左子树内部的答案和右子树内部的答案。
由于每个节点都可能作为起点，并向下遍历一遍，所以最坏时间复杂度是 O(n^2)，递归栈空间是 O(h)。

### 前缀和

使用前缀和记录从根到当前节点的路径和。递归到某个节点时，将它作为路径终点，
设当前前缀和为 currentSum，如果当前路径上曾经出现过 currentSum - targetSum，
说明从那个前缀和之后到当前节点的这段路径和等于 targetSum。

用 HashMap 记录当前路径上每个前缀和出现次数。进入节点时加入当前前缀和，离开节点时撤销，避免影响其他分支。

时间复杂度：O(n)

原因：每个节点只会被访问一次；每次访问节点时，对 HashMap 的查询、插入、删除平均都是 O(1)。

空间复杂度：O(n)

1. HashMap 最多存当前路径上的前缀和，最坏情况下树退化成链表，高度为 n，所以是 O(n)。
2. 递归调用栈也取决于树高，最坏 O(n)，平衡树时 O(log n)。
