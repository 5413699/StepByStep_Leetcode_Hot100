84. 柱状图中最大的矩形

给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 `1`。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

示例 1：

```text
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形面积为 10。
```

示例 2：

```text
输入：heights = [2,4]
输出：4
```

提示：

- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`

相关数据结构：数组、栈
方法：单调栈
记录：20260629

## 面试版思路

这题可以先把每一根柱子都看成一次候选矩形的高度。假设当前柱子的高度是 `h`，那么以它为高度的最大矩形，左右两边可以一直扩展，直到遇到第一个高度小于 `h` 的柱子。因为这两个更矮的柱子会挡住矩形继续扩展，所以矩形宽度就是右边第一个更矮柱子的位置减去左边第一个更矮柱子的位置再减一。

如果对每根柱子都暴力向左右扫描，最坏会是 `O(n^2)`。因此使用单调递增栈优化。栈里存柱子的下标，并且这些下标对应的高度保持递增。

从左到右遍历时，如果当前柱子比栈顶柱子更矮，就说明当前柱子是栈顶柱子右边第一个更矮的位置，栈顶柱子的右边界已经确定，可以弹出并计算面积。弹出后，新的栈顶就是它左边第一个更矮的位置，所以宽度是 `i - stack.peek() - 1`。

为了统一处理边界，可以在数组左右各加一个高度为 `0` 的哨兵。左哨兵保证弹栈后栈里还有元素作为左边界；右哨兵保证遍历结束时所有剩余柱子都会被弹出结算。

## 代码要点

- 使用 `int[] barChart = new int[heights.length + 2]` 创建带左右哨兵的新数组，`int` 默认值为 `0`。
- 使用 `System.arraycopy(heights, 0, barChart, 1, heights.length)` 把原数组复制到哨兵数组中间。
- 栈里存的是下标，不是高度，因为计算宽度需要位置。
- 判断是否弹栈时比较的是 `barChart[stack.peek()] > barChart[i]`。
- 弹出的柱子提供矩形高度；当前下标 `i` 提供右边界；弹出后新的栈顶提供左边界。
- 宽度公式是 `i - stack.peek() - 1`，左右两个更矮边界本身不能算入矩形。

## 易错点

- 栈里存的是下标，不是高度，因为计算宽度需要位置。
- 栈应维护从栈底到栈顶高度递增；遇到更矮高度时持续弹栈。
- 弹出后再取新的栈顶作为左边界，不能用弹出的前一个位置随便代替。
- 没有右侧哨兵时，遍历结束后还要清算栈中剩余柱子；加哨兵可以简化这一步。
- 如果为了加左右哨兵复制数组，可以使用 `System.arraycopy(heights, 0, arr, 1, heights.length)`。注意方法名是全小写的 `arraycopy`，不是 `ArrayCopy` 或 `arrayCopy`。
- 面试表达中要说“覆盖范围内的柱子都不能低于当前高度”，不要说成“不能高于当前高度”。
- 当前柱子更矮时，结算的是栈顶那些更高的旧柱子，不是结算当前柱子。

## 复杂度

- 时间复杂度：`O(n)`。每个柱子最多入栈一次、出栈一次。
- 空间复杂度：`O(n)`。额外数组和单调栈都会占用线性空间。
