155. 最小栈

设计一个支持 `push`、`pop`、`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类：

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素 `val` 推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。

示例 1：

```text
输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]
```

解释：

```java
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin(); // 返回 -3
minStack.pop();
minStack.top();    // 返回 0
minStack.getMin(); // 返回 -2
```

提示：

- `-2^31 <= val <= 2^31 - 1`
- `pop`、`top` 和 `getMin` 操作总是在非空栈上调用
- `push`、`pop`、`top` 和 `getMin` 最多被调用 `3 * 10^4` 次

## 面试版思路

这道题要求 `getMin()` 在 `O(1)` 时间内返回当前栈的最小值，所以不能在查询时遍历整个栈。可以额外维护一个辅助栈 `minStack`，让它和普通栈 `stack` 保持相同高度：普通栈每压入一个元素，辅助栈就压入“当前栈状态下的最小值”。

当 `push(val)` 时，普通栈压入 `val`；辅助栈如果为空，就压入 `val`，否则压入 `Math.min(val, minStack.peek())`。这样 `minStack.peek()` 始终表示当前栈里的最小值。

当 `pop()` 时，两个栈同步弹出，使辅助栈的栈顶自然回退到上一个栈状态对应的最小值。

## 代码要点

- `stack` 存储真实入栈元素。
- `minStack` 存储每一层栈状态对应的最小值。
- `push(val)` 时，`minStack` 压入的是 `val` 和旧最小值之间的较小值。
- `pop()` 时两个栈要同步弹出，因为普通栈退回上一层，最小值记录也要退回上一层。
- `top()` 返回 `stack.peek()`。
- `getMin()` 返回 `minStack.peek()`。

## 本题新用到的栈函数

- `new Stack<>()`：创建一个空栈。
- `push(x)`：把元素压入栈顶。
- `pop()`：弹出并返回栈顶元素。
- `peek()`：只查看栈顶元素，不删除。
- `isEmpty()`：判断栈是否为空；第一次 `push` 时需要先判断，避免对空栈 `peek()`。
- `Math.min(a, b)`：返回两个数中的较小值，本题用来维护当前最小值。

## 易错点

- 构造器里要真正创建对象：`stack = new Stack<>();`，不能写成 `this.stack = stack;`。
- `Stack<Integer>` 本身没有 `getMin()` 方法，最小值来自自己维护的 `minStack.peek()`。
- 第一次 `push` 时 `minStack` 为空，不能直接 `minStack.peek()`。
- `minStack` 不是只保存“新出现的最小值”，而是保存“每一层对应的当前最小值”，所以它要和普通栈等高。
- 本地项目中额外保留了 `M155_Min_Stack` 作为样例入口；提交 LeetCode 时只需要提交 `class MinStack`。

## 复杂度

- 时间复杂度：`push`、`pop`、`top`、`getMin` 都是 `O(1)`。
- 空间复杂度：`O(n)`，其中 `n` 是栈中元素个数，辅助栈需要同步保存每一层的最小值。
