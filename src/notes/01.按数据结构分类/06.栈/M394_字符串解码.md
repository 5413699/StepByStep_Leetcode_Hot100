394. 字符串解码

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为：`k[encoded_string]`，表示方括号内部的 `encoded_string` 正好重复 `k` 次。`k` 保证为正整数。

可以认为输入字符串总是有效的；输入字符串中没有额外空格，且方括号总是符合格式要求。原始数据不包含数字，所有数字只表示重复次数 `k`，例如不会出现 `3a` 或 `2[4]`。

测试用例保证输出长度不会超过 `10^5`。

示例 1：

```text
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

示例 2：

```text
输入：s = "3[a2[c]]"
输出："accaccacc"
```

示例 3：

```text
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

示例 4：

```text
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

提示：

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `[]` 组成
- `s` 保证是一个有效输入
- `s` 中所有整数的取值范围为 `[1, 300]`

## 面试版思路

把字符串解码看成一层一层进入括号和退出括号的过程。

遍历字符串时，用 `num` 记录当前读到的重复次数，用 `cur` 记录当前括号层正在构造的字符串。遇到数字时累积 `num`；遇到 `[` 时，说明要进入新的一层括号，因此把当前重复次数和进入括号前已经构造好的字符串分别压入两个栈，并重置 `num` 和 `cur`。遇到 `]` 时，说明当前括号层结束，从栈中取出重复次数和上一层字符串，把当前 `cur` 重复指定次数后拼回上一层。遇到普通字母时，直接追加到当前 `cur`。

核心记忆句：

```text
遇到 [：保存上一层状态，进入新层
遇到 ]：结束当前层，弹出上一层并合并
```

## 代码要点

- `countStack` 保存进入当前括号层前读到的重复次数。
- `stringStack` 保存进入当前括号层前，上一层已经拼好的字符串。
- `cur` 表示当前层正在构造的字符串；不在括号内时，它就是目前已经解码出的结果。
- 多位数字用 `num = num * 10 + (c - '0')` 累积，例如 `300[a]` 会依次得到 `3`、`30`、`300`。
- 遇到 `[` 后要把 `num` 重置为 `0`，把 `cur` 重置为新的 `StringBuilder`。
- 遇到 `]` 时，用 `pop()` 取出上一层状态，不是 `push()`。

## 易错点

- 判断数字建议用 `Character.isDigit(c)`，不要把 `c - '0'` 再和字符 `'0'`、`'9'` 比较。
- `if / else if / else` 必须互斥；如果写成多个独立 `if`，数字或括号可能会被错误追加到 `cur`。
- `Stack.pop()` 不带参数，表示弹出栈顶元素。
- 不要写 `cur.append(cur)` 来做重复，因为 `StringBuilder` 是可变对象，会一边读取一边修改自己。
- 结束时返回 `cur.toString()`，不是直接返回 `StringBuilder`。

## 复杂度

- 时间复杂度：`O(n + L)`，其中 `n` 是输入长度，`L` 是最终解码字符串长度；实际拼接每个输出字符都会被写入。
- 空间复杂度：`O(d + L)`，其中 `d` 是括号嵌套深度，`L` 来自构造结果字符串。
