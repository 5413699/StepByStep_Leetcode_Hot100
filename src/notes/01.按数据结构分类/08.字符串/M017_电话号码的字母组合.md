17. 电话号码的字母组合

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按任意顺序返回。

数字到字母的映射与电话按键相同，`1` 不对应任何字母。

示例 1：

```text
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

示例 2：

```text
输入：digits = "2"
输出：["a","b","c"]
```

提示：

- `1 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字

## 面试版思路

这道题可以用回溯。首先用 `String[] map` 建立数字到字母集合的映射，例如 `map[2] = "abc"`。递归函数中，`index` 表示当前正在处理 `digits` 的第几个数字，`path` 表示当前已经构造出的字母组合前缀。

每一层递归先取出当前数字对应的字母集合，然后遍历其中每个字母。每次选择一个字母加入 `path`，递归处理下一个数字；递归返回后撤销这个字母，让当前层继续尝试下一个字母。

当 `index == digits.length()` 时，说明每个数字都已经选择了一个对应字母，形成了完整组合，此时把 `path.toString()` 加入答案。

## 代码要点

- `map` 使用长度为 `10` 的字符串数组，让数字字符可以直接通过 `digits.charAt(index) - '0'` 转成下标。
- `path` 使用 `StringBuilder`，便于选择时 `append`，回溯时 `deleteCharAt(path.length() - 1)`。
- 递归参数 `index` 表示当前处理到第几个数字，下一层传 `index + 1`。
- 终止条件要放在递归函数开头，避免 `index == digits.length()` 时继续访问 `digits.charAt(index)`。

## 练习关注点

- 本题的每一层递归对应一个数字位置，不是对应某一个固定字母。
- 当前层的 `for` 循环负责枚举当前数字可以选择的所有字母。
- 递归返回后，说明以当前字母为前缀的所有后续组合已经枚举完成，因此要撤销当前字母。

## 易错点

- `map` 如果只从 `"abc"` 开始存，会导致数字字符转下标后错位；需要保留 `0` 和 `1` 的空占位。
- 递归时应传 `index + 1`，不要传 `index++`。后置自增会先把旧值传入递归，导致一直处理同一位数字，最终栈溢出。
- `toCharArray` 是方法，调用时要写成 `toCharArray()`。
- 空字符串输入时应返回空列表，避免得到包含空字符串的答案。

## 复杂度

设 `n = digits.length()`：

- 时间复杂度：`O(4^n * n)`。最多每个数字有 4 个字母，每生成一个组合需要拷贝长度为 `n` 的字符串。
- 空间复杂度：不算答案为 `O(n)`，主要是递归深度和 `path`；如果计算答案存储，最坏为 `O(4^n * n)`。
