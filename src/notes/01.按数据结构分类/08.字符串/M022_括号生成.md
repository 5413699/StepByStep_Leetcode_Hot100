22. 括号生成

数字 `n` 代表生成括号的对数。请设计一个函数，用于生成所有可能并且有效的括号组合。

示例 1：

```text
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

示例 2：

```text
输入：n = 1
输出：["()"]
```

提示：

- `1 <= n <= 8`

<!-- codex-leetcode-start -->

相关数据结构：字符串
方法：回溯、括号合法性约束
记录：20260615

## 面试版思路

把括号生成看成逐个位置做选择。

对于每个位置，只要左括号数量还小于 `n`，就可以尝试放入左括号；只要右括号数量小于左括号数量，就可以尝试放入右括号，这样可以保证任意前缀都是合法的。

每次放入一个括号后，递归探索以当前 `path` 为前缀的所有合法组合；递归返回后撤销本次选择，让当前层继续尝试其他合法选择。

当 `path` 长度达到 `2 * n` 时，说明已经形成一个完整合法组合，将其加入答案。

## 代码要点

- `left` 表示当前已经放入的左括号数量，`right` 表示当前已经放入的右括号数量。
- `left < n`：左括号还没用完，可以尝试放 `'('`。
- `right < left`：右括号数量不能超过左括号数量，可以尝试放 `')'`。
- `StringBuilder.append(...)` 用来做选择。
- `path.deleteCharAt(path.length() - 1)` 用来撤销当前选择，也就是删除路径末尾刚刚加入的括号。
- `path.toString()` 会生成一个新的 `String` 快照；后续修改 `StringBuilder path` 不会影响已经加入答案的字符串。

## 易错点

- 两个 `if` 不是同时放左右括号，而是在同一层递归里依次尝试两个合法分支。
- 递归后两个分支都要回溯，因为无论刚才 append 的是 `'('` 还是 `')'`，返回时都要恢复到进入该分支前的状态。
- 加入答案时不能写 `new StringBuilder(path)`，答案类型是 `List<String>`，应使用 `path.toString()`。

## 复杂度

- 时间复杂度：`O(C_n * n)`，其中 `C_n` 是第 `n` 个卡特兰数，表示合法括号组合数量；每个答案长度为 `2n`。
- 空间复杂度：`O(n)`，不计答案数组时，递归深度和 `path` 长度都是 `O(n)`。

## 掌握状态

- 状态：提示后完成，需要二刷。
- 当前主要卡点：递归分支不是同时执行，而是“做选择 -> 递归探索 -> 撤销选择 -> 尝试下一种选择”。
- 二刷重点：口述 `right < left` 为什么能保证前缀合法，并手写 `StringBuilder` 的 append / delete 回溯流程。
