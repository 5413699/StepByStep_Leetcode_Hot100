# M139-单词拆分

[力扣原题](<https://leetcode.cn/problems/word-break/>)

<details>
<summary>题干、示例与限制</summary>

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s`，则返回 `true`。

**注意：** 不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

## 示例

### 示例 1

```text
输入：s = "leetcode", wordDict = ["leet", "code"]
输出：true
解释："leetcode" 可以由 "leet" 和 "code" 拼接成。
```

### 示例 2

```text
输入：s = "applepenapple", wordDict = ["apple", "pen"]
输出：true
解释："applepenapple" 可以由 "apple"、"pen"、"apple" 拼接成。
注意：字典中的单词可以重复使用。
```

### 示例 3

```text
输入：s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出：false
```

## 提示

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 仅由小写英文字母组成
- `wordDict` 中的所有字符串互不相同

                    memo[start] = true;
                    return true;
                }
            }
        }

        memo[start] = false;
        return false;
    }
}

## 复杂度与边界

令 n = s.length()，m = wordDict.size()，L 为最长单词的长度。

- **纯递归**：最坏情况指数增长。不同切分路径可以反复到达同一个 start；例如连续 a 后接 b、字典包含 a 和 aa 时，失败后缀会被重复搜索。因为字典单词互不相同，每一串切分位置至多对应一条路径，递归调用总数可用 O(2^n) 保守界定；每个非终止调用最多遍历 m 个单词并比较至多 L 个字符，故 O(m × L × 2^n) 是保守上界。递归栈 O(n)。
- **记忆化搜索**：需要完整计算的 start 只有 0 到 n - 1，每个至多计算一次。每个状态枚举 m 个单词，startsWith 至多比较 L 个字符，总时间 O(n × m × L)。缓存 O(n)，递归栈 O(n)，额外空间合计 O(n)。
- **下标到达 n**：先返回 true，再访问 memo；Boolean[n] 的有效下标只有 0 到 n - 1。
- **失败也要缓存**：false 表示整个后缀已经确认无法拆分；只有全部候选失败后才能写入。null 不能当成失败，否则尚未计算的状态会被提前剪掉。
- **不受此前路径影响**：字典单词允许重复使用，start 相同就意味着后缀和可用选项相同，不需要记录已使用单词。
- **无法完整匹配就不前进**：startsWith(word, start) 在剩余长度不足或内容不同时返回 false。单词均非空，因此每次递归 start 严格增加，最大深度为 n + 1。
