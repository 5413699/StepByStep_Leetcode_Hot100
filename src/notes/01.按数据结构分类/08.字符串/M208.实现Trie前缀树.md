208. 实现 Trie（前缀树）

Trie（发音类似 "try"）或者说前缀树，是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有很多应用场景，例如自动补全和拼写检查。

请你实现 `Trie` 类：

- `Trie()` 初始化前缀树对象。
- `void insert(String word)` 向前缀树中插入字符串 `word`。
- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`；否则返回 `false`。
- `boolean startsWith(String prefix)` 如果之前已经插入的字符串中存在以 `prefix` 为前缀的单词，返回 `true`；否则返回 `false`。

示例：

输入：

```text
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
```

输出：

```text
[null, null, true, false, true, null, true]
```

解释：

```java
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 true
trie.search("app");     // 返回 false
trie.startsWith("app"); // 返回 true
trie.insert("app");
trie.search("app");     // 返回 true
```

提示：

- `1 <= word.length, prefix.length <= 2000`
- `word` 和 `prefix` 仅由小写英文字母组成
- `insert`、`search` 和 `startsWith` 调用次数总计不超过 `3 * 10^4` 次

## 面试版思路

把 Trie 设计成节点类。每个节点用 `children` 数组表示从当前节点出发，26 个小写字母中是否存在后续路径；用 `isEnd` 表示从根节点到当前节点形成的字符串是否是一个已经插入过的完整单词。

插入时从根节点开始遍历字符串。每看到一个字符，就用 `c - 'a'` 得到它在 `children` 中的下标。如果当前字符对应的子节点不存在，就创建一个新节点，用来记录这个新前缀；然后移动到这个子节点。整个单词走完后，把当前节点标记为单词结尾。

查找单词和查找前缀时，都是从根节点按字符路径往下走。如果中途某个子节点不存在，说明路径断了，直接返回 `false`。区别在于：`startsWith` 只要能走完整个前缀就返回 `true`；`search` 还必须检查最后停下的节点 `isEnd == true`，这样才能确认它是被插入过的完整单词，而不只是某个单词的前缀。

## 代码要点

- `children = new Trie[26]` 不是存 26 个字符，而是存当前节点通向 26 个小写字母的 26 条可能路径。
- `null` 表示这条字符路径还不存在。
- 插入时遇到 `null` 就创建节点；查询时遇到 `null` 就说明目标不存在。
- 重复字符不需要特殊处理，因为每个节点都有自己独立的 `children` 数组。例如 `"apple"` 中两个 `p` 位于不同层级，虽然下标都是 `'p' - 'a'`，但它们属于不同节点。
- `search` 和 `startsWith` 的路径查找逻辑相同，可以抽取成 `findNode`，减少重复。

## 练习关注点

- 明确 Trie 节点的含义：一个节点通常表示从根节点走到当前节点形成的某个前缀。
- 每个节点至少需要两类信息：子节点引用，以及当前节点是否是某个完整单词的结尾。
- 区分 `search` 和 `startsWith`：前者必须走完整个单词并检查结尾标记，后者只要前缀路径存在即可。
- 本题限定只包含小写英文字母，因此每个节点可以用长度为 `26` 的数组保存子节点。

## 易错点

- 不要把 `children` 和 `isEnd` 写成构造方法里的局部变量；它们必须是每个节点对象的成员变量。
- `String` 不能直接使用增强 `for`，需要 `word.toCharArray()` 或 `charAt(i)`。
- `insert` 的判断条件是 `children[index] == null` 时创建节点。
- `search` 和 `startsWith` 的判断条件是 `children[index] == null` 时返回 `false`。
- `boolean` 方法不能返回 `null`。

## 复杂度

设输入字符串长度为 `L`：

- `insert` 时间复杂度：`O(L)`，空间复杂度最坏为 `O(L)`，只在新路径不存在时创建节点。
- `search` 时间复杂度：`O(L)`，空间复杂度：`O(1)`。
- `startsWith` 时间复杂度：`O(L)`，空间复杂度：`O(1)`。
