# M763. 划分字母区间

[LeetCode 题目链接](https://leetcode.cn/problems/partition-labels/)

给定一个字符串 `s`，将它划分为尽可能多的片段，使同一字母最多出现在一个片段中。返回每个片段的长度。

## 示例

```text
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：划分结果为 "ababcbaca"、"defegde"、"hijhklij"。
```

```text
输入：s = "eccbbbbdec"
输出：[10]
```

## 提示

- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

## 面试版思路

先遍历一次字符串，用长度为 `26` 的数组记录每个字母最后出现的下标。

第二次遍历时，维护当前片段的起点 `start` 和必须覆盖的最远下标 `end`。每遇到一个字符，就用该字符最后出现的位置扩大 `end`。当 `i == end` 时，说明当前片段中出现过的所有字符都不会在片段外再次出现，此时可以安全切割，并记录长度 `end - start + 1`。

## 为什么这样能得到尽可能多的片段

当前片段只要包含了某个字母，就必须延伸到该字母最后一次出现的位置；扫描过程中遇到的新字母可能继续扩大这个必要边界。因此，在第一次到达所有已出现字母共同要求的最远边界时立即切割，是当前片段能够取得的最短合法长度。每个片段都尽早结束，最终片段数量就最多。

## 代码要点

- `last[s.charAt(i) - 'a'] = i`：利用小写字母范围固定的条件，记录每个字母最后出现的位置。
- `end = Math.max(end, last[s.charAt(i) - 'a'])`：片段右边界只能扩大，不能被最后位置更靠前的字符缩小。
- `i == end`：表示已经扫描完当前片段必须包含的全部范围，可以切割。
- `end - start + 1`：两个闭区间下标之间的元素数量需要加一。
- 切割后执行 `start = end + 1`，开始寻找下一个片段。

## 易错点

- `last` 的下标代表字母，应使用 `s.charAt(i) - 'a'`，不能直接使用字符串下标 `i`。
- 更新 `end` 时必须使用 `Math.max`。直接赋值可能让右边界缩小，产生非法切割。
- `String.charAt` 是方法，调用时使用 `s.charAt(i)`，不能写成 `s.charAt[i]`。
- 返回值是每个片段的长度列表，不是子字符串列表。
- 片段长度是 `end - start + 1`，注意闭区间的加一。

## 复杂度

- 时间复杂度：`O(n)`，字符串被完整扫描两次。
- 空间复杂度：`O(1)`，长度为 `26` 的数组大小固定；不计返回结果。

## 面试表达

我先记录每个字母最后出现的位置，然后贪心地确定每个片段的最早合法结束点。扫描当前片段时，不断用遇到字符的最后位置扩大右边界；当扫描下标追上右边界时，片段内所有字母都不会出现在后面，因此立即切割。这个片段已经是当前能取得的最短合法片段，所以能让最终片段数尽可能多。
