79. 单词搜索

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word`。如果 `word` 存在于网格中，返回 `true`；否则返回 `false`。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

示例 1：

```text
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
输出：true
```

示例 2：

```text
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
输出：true
```

示例 3：

```text
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
输出：false
```

相关数据结构：矩阵
方法：DFS、回溯、网格搜索
记录：20260616

## 面试版思路

把每个格子都尝试作为单词起点。如果当前格子能匹配 `word[0]`，就从这个格子开始做 DFS，判断从当前位置能否继续匹配 `word[k]` 及其后续字符。

DFS 中先排除越界、当前路径中已经访问过、当前字符不匹配这三种失败情况。如果当前字符匹配，并且 `k` 已经是单词最后一个下标，说明整个单词已经找到，返回 `true`。

否则标记当前格子已经被当前路径使用，然后向上下左右四个方向继续搜索 `word[k + 1]`。如果任意方向成功，就返回 `true`；如果四个方向都失败，撤销当前格子的访问标记，并返回 `false`。

## 代码要点

- `dfs(board, word, i, j, k, visited)` 表示：站在 `board[i][j]`，尝试匹配 `word` 的第 `k` 个字符。
- `boolean[][] visited = new boolean[board.length][board[0].length]` 创建一个和网格同样大小的访问标记数组。
- `visited[i][j] == true` 表示当前搜索路径已经用过这个格子，不能重复使用。
- DFS 入口判断顺序可以记成：越界 -> 用过 -> 不匹配 -> 匹配且完成。
- 当前格子匹配后，先 `visited[i][j] = true`，再探索四个方向。
- 四个方向都走不通时，使用 `visited[i][j] = false` 撤销当前选择。

## 易错点

- `new boolean[board.length][board[0].length]` 中，`board.length` 是行数，`board[0].length` 是列数；boolean 数组默认值是 `false`。
- 越界判断要包含小于 0 和等于长度的情况：`i < 0 || i >= board.length || j < 0 || j >= board[0].length`。
- 必须先判断当前字符是否匹配，再判断 `k == word.length() - 1`。否则走到最后一层时，可能还没确认字符相等就直接返回 `true`。
- 回溯撤销要在当前格子的后续方向探索结束后进行，不要在每个方向刚失败时就提前撤销当前格子。
- 如果某个方向已经成功，直接返回 `true` 也能通过；更规整的写法是在返回前恢复 `visited[i][j] = false`。

## 复杂度

- 时间复杂度：`O(m * n * 4^L)`，其中 `m` 和 `n` 是网格行列数，`L` 是 `word.length()`。因为每个格子都可能作为起点，搜索过程中最多向四个方向扩展。
- 空间复杂度：`O(m * n + L)`，`visited` 占 `O(m * n)`，递归深度最多为 `L`。

## 掌握状态

- 状态：提示后完成，需要二刷。
- 当前主要突破：理解 DFS 入口处多个 `if` 不是零散判断，而是一层固定顺序的安检。
- 当前主要卡点：二维 `visited` 初始化、成功条件必须建立在字符匹配之后、回溯撤销时机。
- 二刷重点：不看代码写出 DFS 的判断顺序，并口述为什么同一条路径不能重复使用格子。
