295. 数据流的中位数

中位数是有序整数列表中的中间值。如果列表大小为偶数，中位数是中间两个数的平均值。

实现 `MedianFinder` 类：

- `MedianFinder()`：初始化对象。
- `void addNum(int num)`：将整数加入数据流。
- `double findMedian()`：返回当前所有元素的中位数。

示例：

```text
输入：
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]

输出：
[null, null, null, 1.5, null, 2.0]
```

提示：

- `-10^5 <= num <= 10^5`
- 调用 `findMedian` 前至少已经加入一个元素
- 最多调用 `5 * 10^4` 次 `addNum` 和 `findMedian`

## 第一反应

好久没有做 LeetCode，先从已经接触过的堆恢复手感。中位数只和有序序列中间的一个或两个元素有关，因此不需要在每次加入数字后完整排序，可以把数据维护成较小和较大的两半。

## 面试版思路

使用两个堆维护数据流：

- `small` 是最大堆，保存较小的一半，堆顶是这一半的最大值。
- `large` 是最小堆，保存较大的一半，堆顶是这一半的最小值。

始终维护两个不变量：

```text
small 中的所有元素 <= large 中的所有元素
small.size() == large.size()
或者 small.size() == large.size() + 1
```

加入新元素时，如果 `small` 为空，或者 `num <= small.peek()`，就先加入 `small`；否则加入 `large`。然后根据两个堆的数量关系移动堆顶：

- `small` 比 `large` 多两个元素时，把 `small.poll()` 移到 `large`。
- `large` 比 `small` 多一个元素时，把 `large.poll()` 移到 `small`。

这样，元素总数为奇数时，`small` 会比 `large` 多一个元素，中位数是 `small.peek()`；元素总数为偶数时，两个堆大小相等，中位数是两个堆顶的平均值。

## 推导过程

对于有序数据 `[1, 2, 3, 4, 5, 6]`，只需要快速取得较小一半的最大值 `3` 和较大一半的最小值 `4`。因此较小一半使用最大堆，较大一半使用最小堆。

以依次加入 `1、2、3、4、5` 为例：

```text
加入 1：small = [1]，large = []
加入 2：small = [1]，large = [2]
加入 3：先进入 large，再把 large 堆顶 2 移到 small
加入 4：进入 large，两个堆大小相等
加入 5：先进入 large，再把 large 堆顶 3 移到 small
```

每次移动的都是堆顶，因此能在不完整排序的情况下持续维护中间边界。

## 代码要点

- Java 的 `PriorityQueue` 默认是最小堆。
- 最大堆使用 `(a, b) -> Integer.compare(b, a)`，反转默认比较方向；相比 `b - a`，这种写法不依赖减法，通用场景下更安全。
- `small.isEmpty()` 必须放在 `small.peek()` 之前，利用 `||` 短路避免访问空堆堆顶。
- 一次只加入一个元素，因此每次加入后至多进行一次堆顶移动即可恢复数量平衡。
- 两个堆是 `MedianFinder` 的长期状态，必须声明为成员变量。

## 本次易错点

- 把 `PriorityQueue` 拼成了不存在的 `PriorQueue`。
- 在构造器中写 `PriorityQueue<Integer> small = ...` 会重新声明同名局部变量，遮蔽成员变量；构造结束后成员变量仍为 `null`。初始化成员变量时不能再次写类型。
- `small` 为空时先加入元素后，如果继续执行另一个独立的插入 `if`，同一个数字可能被加入两次；插入判断应组成一个 `if/else`。
- 应使用 `small.peek()` 作为两半数据的分界线；`large` 可能为空，不能直接用 `large.peek()` 判断。
- `peek` 是方法，需要写成 `peek()`。
- `large.offer(num)` 后不能漏写分号。

## 复杂度

- `addNum`：每次至多执行常数次堆操作，时间复杂度为 `O(log n)`。
- `findMedian`：只读取堆顶，时间复杂度为 `O(1)`。
- 两个堆保存全部元素，空间复杂度为 `O(n)`。
