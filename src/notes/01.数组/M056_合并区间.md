# M056. 合并区间
以数组 intervals 表示若干个区间的集合，
其中单个区间为 intervals[i] = [starti, endi]。
请你合并所有重叠的区间，并返回 一个不重叠的区间数组，
该数组需恰好覆盖输入中的所有区间 。

示例 1：
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].

示例 2：
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间。

示例 3：
输入：intervals = [[4,7],[1,4]]
输出：[[1,7]]
解释：区间 [1,4] 和 [4,7] 可被视为重叠区间。

提示：
1 <= intervals.length <= 104
intervals[i].length == 2
0 <= starti <= endi <= 104



1.边界情况处理，假如只有一个区间，或者没有区间，无需合并，直接返回即可
2.对各个区间按照左端点的值进行排序
3.用第一个区间暂时记录最终不重叠区间的左端点和右端点
4.用可变长的ArrayList记录最终不重叠的区间数组
5.从第二个区间开始遍历排序后的区间[[1,3],[2,6],[8,10],[15,18]]
6.假如当前区间的右端点大于下一区间的左端点
    说明发生重叠，需要更新区间的右端点为两区间右端点的最大值
7.假如当前区间的右端点小于下一区间的左端点[1,6],[8,10]
    说明无重叠，当前区间可加入最终的不重叠区间数组中
8.更新新区间
9.将最后一个区间加到结果中
10.将结果转换为int[][]类型
